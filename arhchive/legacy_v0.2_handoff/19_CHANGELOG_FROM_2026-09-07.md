# 19. Changelog from the 2026-09-07 Grammar Checkpoint

The prior checkpoint already established component trees, component signatures, low-context grammar, and projection hierarchy. The following are the major post-checkpoint changes.

## 1. `Object` split into Entity and Feature

Old ambiguity:

- object as physical body;
- object as focus quantity/semantic target.

New model:

- **Entity** = reference/co-reference anchor;
- **Feature** = actual scientific characteristic/relation;
- **Quantity** = quantitative Feature.

This is the largest conceptual reset.

## 2. Mandatory Entity grounding

A Physical Feature now requires Entity grounding. Bare kind arithmetic is downgraded to an ungrounded kind expression/skeleton.

## 3. Feature Kind definitions include Entity-binding patterns

Density/concentration/fraction distinctions are now defined structurally through repeated/distinct Entity variables and relations such as `PartOf`.

## 4. Lambda/dependent-function interpretation strengthened

Feature Kinds are now explicitly treated as constrained lambda-like/dependent schemata.

## 5. Entity granularity controls definition granularity

Height/extent/distance examples established resolution-relative primitiveness.

## 6. Site/Surface/Occupancy grammar introduced

Spatial definitions now use Occupancy → Site/Boundary → measure. Surface is no longer equated with boundary.

## 7. Temporal occurrence grammar introduced

Change is comparison of Feature occurrences; Rate is a partial differential constructor. Time/clock structure is deliberately delegated to mature theories rather than overdefined.

## 8. Definition / Law / Constitutive Relation split made explicit

This became necessary in mechanics, electromagnetism, and continuum mechanics.

## 9. Field and tensor-generation grammar developed

Tensor order can often be inferred from semantic input/output slots, tensor products, gradients, contractions, and response maps.

## 10. Balance/conservation law schema introduced

Continuity equations for mass/charge/species/momentum/energy now share a generic accumulation/flux/source structure.

## 11. Electrodynamics and continuum mechanics stress-tested

Maxwell integral/differential forms, material derivative, stress/strain, Cauchy momentum, constitutive relations were integrated into the grammar.

## 12. Moment and Potential families explored

Moment constructions compress center-of-mass/inertia/multipole/torque/angular-momentum families. `Potential` was recognized as major lexical overload with multiple distinct semantic genealogies.

## 13. Minimal-domain-knowledge validation added

The grammar is now testable by asking how much semantic structure survives when conventional physics names/definitions are hidden.

## 14. Current strategic result

The project is no longer primarily "quantity nomenclature decomposition". It is becoming a **grounded generative definition grammar for scientific Features, with controlled projection to dimensions and names**.
