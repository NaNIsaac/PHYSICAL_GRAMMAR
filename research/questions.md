# Research Questions

Questions are allowed to remain unresolved. A question is not a grammar commitment.

- **Q001** — Is role-sensitive grounding necessary as an explicit reusable mechanism?
- **Q002** — Are prerequisites/conditions/reference relations instances of a more generic semantic dependency?
- **Q003** — Can naming modifiers be predicted from distinctions preserved by the semantic construction?
- **Q004** — Is Rich Physical Dimension (RPD) useful beyond the development cases that motivated it?
- **Q005** — How should non-Entity arguments and indices (time, wavelength, mode index, etc.) be represented?
- **Q006** — How should held-fixed and constrained derivative semantics be represented?
- **Q007** — Is Site an Entity role/subtype or a distinct semantic sort?
- **Q008** — How should geometric, probabilistic, and manifold-valued spaces be typed?

- **Q009** — Should Physical Feature remain an analysis-level semantic umbrella, or appear explicitly in a future kernel?
- **Q010** — What is the smallest stable interface among referential, type, construction, abstraction, geometry, process, restriction, realization and nomenclature layers?
- **Q011** — Which recurring constructions are genuine grammar operations rather than typed mathematics plus semantic classification?
- **Q012** — Does Process Structure justify an independent reusable calculus across unrelated physical domains?
- **Q013** — Can Restriction Context remain a thin cross-cutting service without collapsing references, regimes, boundary conditions and variable binding into one Condition object?
- **Q014** — How should statement-level status distinguish definition, identity, constraint, constitutive relation, evolution/conservation law, model relation and empirical fit?
- **Q015** — Can semantic identity be represented as a certificate assembled from structure, roles, references, restrictions, process and domain seeds?
- **Q016** — How should a stable quantity/feature registry distinguish semantic identity, descriptor, conventional name, symbol, alias and historical identifier?
- **Q017** — Which structure-based search/lint tasks show measurable advantage over generic typed expression trees and lexical/ontology baselines?
- **Q018** — Which post-v0.5 structural/interface/process/restriction trials should be reconstructed first as repository-native benchmarks?
