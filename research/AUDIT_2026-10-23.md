## Frozen and provisional

The repository uses its own status vocabulary: Canonical / Working / Candidate / Deferred / Rejected ([docs/08 §1](../docs/08_META_TERMINOLOGY.md)), and FREEZE / PROVISIONAL / DO NOT ADD / DO NOT PROMISE ([docs/05](../docs/05_DECISIONS_AND_OPEN_QUESTIONS.md)). Summary:

- Frozen (docs/05 §2): Scope-relative relevance; Entity; Property and grounding; EntityMap genealogy; Grounding Continuity and Closure; Representation ≠ Projection; projection/refinement DAG where appropriate; `A ~_π B iff π(A)=π(B)`; factorization safety `P = P̄∘π`; exact `~` vs tolerance `≈`; qualified sameness; definition/law/model distinction; VIM boundary.
- Provisional (docs/05 §3): projection static checking; the `safe / unsafe / unknown` interface; positive `Preserves` contracts; task-relative `~_T`; approximate `≈_{T,ε}`; use-after-projection diagnostics; angle and count rich dimensions; contract syntax.
- Strong candidate, not irreversible: Feature → Property (docs/05 §6).
- Findings that are explicitly not grammar changes: R1 role and genealogy, R2 held-fixed conditions, R3 non-grounding dependence, R4 prerequisite structures ([README](../README.md), docs/09).
- Not yet justified as primitives: `Role`, `Condition`, `Observer` ([STATUS](../STATUS.md) evidence clusters 2–3, [ASSESSMENT](ASSESSMENT_2026-09-10.md)).
- Excluded: Distinction node, universal `Same`, exhaustive `Lost(π)`, universal Scope schema, universal semantic distance, a large ontology, automatic reification, a universal `PropertyValue` (docs/05 §4).
